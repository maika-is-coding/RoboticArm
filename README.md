# 伺服馬達控制專案

這是一個基於 Arduino 的伺服馬達控制專案，使用兩個搖桿來控制四個伺服馬達的角度，分別控制機器手臂的基座、肩部、肘部和爪部的運動。每個搖桿的 X 軸和 Y 軸分別控制不同的伺服馬達，通過調整搖桿來實現手臂的運動。

## 硬體需求

- Arduino 板（例如 Arduino UNO）
- 4 個伺服馬達（如 SG90 或類似型號）
- 2 個模擬搖桿
- 跳線

## 接腳連接

- **伺服馬達**：
  - `Base`（基座伺服） -> Pin 3
  - `Shoulder`（肩部伺服） -> Pin 5
  - `Elbow`（肘部伺服） -> Pin 6
  - `Claw`（爪部伺服） -> Pin 9

- **搖桿**：
  - `Joystick1 X` -> Pin A0
  - `Joystick1 Y` -> Pin A1
  - `Joystick2 X` -> Pin A2
  - `Joystick2 Y` -> Pin A3

## 程式碼說明

### 1. 伺服馬達設定
- 這個程式控制四個伺服馬達，分別控制基座、肩部、肘部和爪部的角度。
- 伺服馬達使用 `Servo` 函式庫進行控制。

### 2. 搖桿控制
- 搖桿的 X 軸和 Y 軸分別對應於每個伺服馬達的角度。透過讀取搖桿的模擬輸入值，使用 `mapJoystick` 函式將其映射到 0 到 180 的範圍，以控制伺服馬達的轉動角度。

### 3. 顯示角度
- 每次搖桿的輸入變化時，將伺服馬達的角度傳送到序列埠，顯示在序列阜監控窗中，方便使用者檢查每個伺服的當前角度。

### 4. 延遲控制
- 程式中設置了 50 毫秒的延遲，以減少對伺服馬達的頻繁寫入操作，從而延長伺服馬達的使用壽命。

## 安裝與運行

1. 確保你的 Arduino IDE 已安裝並且可以正常連接你的 Arduino 板。
2. 將程式碼複製到 Arduino IDE 中。
3. 選擇對應的 Arduino 板型與連接埠。
4. 點擊上傳並開始執行。

當你操作搖桿時，四個伺服馬達的角度會相應改變，並且在序列阜監控窗中顯示當前的角度。

## 函式說明

### `mapJoystick(int value)`
此函式將搖桿的輸入值（0 到 1023）映射到伺服馬達所需的角度範圍（0 到 180），並確保輸入值在有效範圍內。

```cpp
int mapJoystick(int value) {
  return constrain(map(value, 0, 1023, 0, 180), 0, 180);
}
